# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on this repository (Security tab). Please do not open a public issue for it.

Things worth a private report:

- a transfer the policy should stop that the gate allows
- an address in OFAC's files that the importer misses or misreads
- a policy or list file that loads without error but is not what it says
